# Project documentation

Documentation for the Primus dApp, a practice-mode blockchain project on the Sepolia testnet. Read these in order when picking the project up.

| File | What it covers |
|------|----------------|
| [PROJECT_STATUS.md](PROJECT_STATUS.md) | Current state, what is done, exactly where work stopped, and the next steps |
| [HANDOFF_PROMPT.md](HANDOFF_PROMPT.md) | The prompt to paste into a new chat to continue the work |
| [PLAN.md](PLAN.md) | Roadmap, locked decisions and the full Phase 4 (registration) design |
| [ARCHITECTURE.md](ARCHITECTURE.md) | How the frontend, contracts and Supabase backend fit together |
| [CONTRACTS.md](CONTRACTS.md) | Every deployed address, constructor value, root, CID and the deployment history |
| [DECISIONS.md](DECISIONS.md) | Decision log with the reasons and the lessons learned |
| [SUPABASE_SETUP.md](SUPABASE_SETUP.md) | Supabase project details, setup progress and the remaining commands |
| [TROUBLESHOOTING.md](TROUBLESHOOTING.md) | Problems already hit and how each was fixed |

The root `README.md` is the public project description. `supabase/README.md` documents the registration backend folder.
